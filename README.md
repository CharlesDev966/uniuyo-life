# UNIUYO Life
A first-person 3D day at the University of Uyo: walk the campus, sit in lectures, and have lunch at the cafeteria.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # static site in dist/

Press G in the game to cycle graphics quality (Low / Medium / High), or add ?q=low|medium|high to the URL.
Timetable, courses and prices are simulated.
